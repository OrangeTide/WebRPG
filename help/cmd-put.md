# PUT: Upload Files

Upload one or more files from your computer into the Virtual File System.

## Command Usage

```
PUT [dest]
```

- `dest`  Optional destination directory. Defaults to the current directory.

## Details

PUT opens your browser's file picker. The files you choose are uploaded into
the destination directory. This is the counterpart to [GET](help:cmd-get),
which downloads a file out of the VFS.
