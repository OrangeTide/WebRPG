# MKDIR: Create a Directory

Create a new directory.

## Command Usage

```
MKDIR [d:]path
```

- `path`  Path of the directory to create.

## Details

MKDIR creates a directory at the given path. The parent directory must already
exist. MD is an alias for MKDIR. To remove a directory later, use
[RMDIR](help:cmd-rmdir).
