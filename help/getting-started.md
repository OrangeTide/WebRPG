# Getting Started

Welcome to WebRPG, a virtual tabletop for roleplaying games. This page is a
quick tour of the interface and where to go next.

## The Desktop

WebRPG runs as a desktop of draggable, resizable windows over a shared game
session. Along the bottom is the dock, a row of tiles for each window. Click a
tile to open or restore its window. Minimized windows return to the dock.

Each window has a title bar. When a window has a help page, a `?` button
appears in its title bar that opens this help browser to the matching topic.

## Core Windows

| Window | Purpose |
|--------|---------|
| Map | The shared play surface: tokens, grid, and fog of war. |
| Chat | Dice rolls and messages shared with the table. |
| Characters | Your character sheets and portraits. |
| Initiative | Turn order during an encounter. |
| Files | Graphical file browser for the Virtual File System. |
| Terminal | A COMMAND.COM shell over the same file system. |
| Help | This help browser. |

## Working with Files

WebRPG stores maps, portraits, and other media on a [Virtual File
System](help:vfs) with lettered drives. You can manage files two ways: the
graphical [File Viewer](help:file-viewer), or the [COMMAND.COM](help:command-com)
terminal for keyboard-driven work.
