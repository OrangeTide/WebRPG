# TYPE: Display a File

Print the contents of a text file to the terminal.

## Command Usage

```
TYPE filespec
```

- `filespec`  Path to the file to display.

## Details

TYPE writes a text file straight to the terminal. It is meant for text, so
binary files such as images will look like garbage. To save a file to your
computer instead, use [GET](help:cmd-get). CAT is an alias for TYPE.
