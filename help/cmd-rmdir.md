# RMDIR: Remove a Directory

Remove an empty directory.

## Command Usage

```
RMDIR path
```

- `path`  Path of the directory to remove.

## Details

RMDIR removes a directory, which must be empty first. Delete any files inside
it with [DEL](help:cmd-del) before removing the directory. RD is an alias for
RMDIR.
